## Adding to it

Every feature is a folder under `configuration/` with its own `install.sh`; the
[manual's dotfiles chapter](https://orchard-manual.netlify.app/the-dotfiles.html)
explains the shape. If you're working with Claude Code, start with `/orchard` —
the repo ships a skill that carries the whole setup (feature folders, the theme
system, bar modules, Hyprland wiring, how to verify a change live), so you can
ask for an addition without explaining any of it first.
